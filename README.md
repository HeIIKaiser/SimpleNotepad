SimpleNotepad for macOS<br>
A lightweight, native macOS text editor inspired by classic Windows Notepad.<br>

I missed the basic notepad from Windows which was one of my most used apps. So I jumbled together one for my macbook. Figured theres probably like 5000 of them but hey, might as well make it as I like it.<br>

Built with Swift and SwiftUI.<br>

Features<br>
1) Plain text editing with monospaced font<br>
2) Open / Save / Save As with native file dialogs<br>
3) Find & Replace with case sensitivity toggle and match counter<br>
4) Go to Line (CMD +  G)<br>
5) Word Wrap toggle (CMD +  Shift + W)<br>
5) Adjustable font size (CMD +  +, CMD +  -, CMD +  0 to reset)<br>
7) Status bar showing line count, word count, and character count<br>
8) Unsaved changes prompt when closing or creating new documents<br>
9) Full Undo/Redo support (native NSTextView)<br>
