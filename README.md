SimpleNotepad for macOS
A lightweight, native macOS text editor inspired by classic Windows Notepad.

I missed the basic notepad from Windows which was one of my most used apps. So I jumbled together one for my macbook. Figured theres probably like 5000 of them but hey, might as well make it as I like it.

Built with Swift and SwiftUI.

Features
Plain text editing with monospaced font
Open / Save / Save As with native file dialogs
Find & Replace with case sensitivity toggle and match counter
Go to Line (CMD +  G)
Word Wrap toggle (CMD +  Shift + W)
Adjustable font size (CMD +  +, CMD +  -, CMD +  0 to reset)
Status bar showing line count, word count, and character count
Unsaved changes prompt when closing or creating new documents
Full Undo/Redo support (native NSTextView)

Keyboard Shortcuts
CMD + N			New document
CMD + O			Open file
CMD + S			Save
CMD + Shift + S	Save As
CMD + F			Find
CMD + H			Find & Replace
CMD + G			Go to Line
CMD + Shift + W	Toggle Word Wrap
CMD + +			Increase font size
CMD + -			Decrease font size
CMD + 0			Reset font size
